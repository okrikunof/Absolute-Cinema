## Соответствие требованиям

| Требование | Текущее состояние |
| --- | --- |
| SwiftUI, iOS 17+ | Сохранены; приложение собрано для iOS Simulator |
| Простой MVVM | Поиск, карточка, оценки и желаемое имеют ViewModel; View не обращаются к SwiftData или UserDefaults |
| Минимум четыре экрана | Поиск, карточка, мои оценки, хочу посмотреть; отдельно форма оценки |
| Хранение | SwiftData: оценки и желаемое; UserDefaults: сортировка |
| Работа с сетью | Отложена по уточнению разработчика; четыре мока остаются источником фильмов |
| Многопоточность | Не реализована; способ демонстрации ожидает уточнения по занятию |
| Unit-тесты | Работа с ними отложена по прямому указанию разработчика |

## Что изменилось

- У поиска появилась небольшая SearchViewModel с фильтрацией по русскому и оригинальному названию.
- «Оценить» открывает форму: черновик сохраняется только кнопкой, закрытие формы отменяет несохранённые изменения.
- Желаемые фильмы сохраняются без обязательной оценки, в отдельной модели и репозитории.
- Личная оценка и желаемое независимы; данные прежних оценок не преобразовывались в новую модель.
- Навигация передаёт Movie из списка, а не повторно ищет ID в MockMovies. Сохранённая карточка больше не зависит от массива моков.
- ViewModel списка оценок имеет одного владельца; View получает сортировку через ViewModel; удаление не вызывает второе ручное чтение поверх revision.

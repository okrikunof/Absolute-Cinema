# Интеграция TMDB

Актуально на 22 октября 2026 года по исходникам. Это описание реализации; доступность реального сервиса последним тестовым прогоном не подтверждена.

## Запросы

TMDBClient (Data/Network/TMDBClient.swift) — actor с URLSession. Базовый адрес https://api.themoviedb.org/3, язык ru-RU, таймаут запроса 20 секунд.

| Метод и путь | Назначение |
| --- | --- |
| GET /search/movie | Поиск: query, include_adult=false, page=1 |
| GET /movie/{id} | Полная карточка, проверка ID ответа |
| GET /authentication/guest_session/new | Создание гостевой сессии для отправки оценки |
| POST /movie/{id}/rating | Отправка числа 1–10 в JSON value с guest_session_id |

Популярные фильмы, рекомендации, последующие страницы поиска, синхронизация watchlist аккаунта и удаление оценки в TMDB не реализованы.

## Данные и ошибки

Decodable-ответы преобразуются в Movie. Результат поиска имеет hasDetails=false; полная карточка — true. Отсутствующие дата, длительность, описание, жанры и постер имеют допустимые значения по умолчанию. Локальный сохранённый снимок может заменить краткий результат при недоступности сети.

JSONParser разбирает JSON в DispatchQueue.global через continuation. Отмена проверяется до и после разбора; уже начатый блок GCD не останавливается. Клиент обрабатывает ошибки подключения, таймаут, HTTP-статусы, некорректный JSON и бизнес-статус ответа POST. UI показывает ошибку и возможность повтора.

## Конфигурация

TMDBConfiguration.load() читает TMDBConfig.plist из Bundle.main. Поддерживаются APIKey и ReadAccessToken. Непустой токен имеет приоритет и передаётся как Authorization: Bearer; иначе ключ передаётся параметром api_key. Локальный файл должен попадать в ресурсы приложения для реального запроса, но оставаться вне Git. Значения не выводить в команды, логи или документацию. Последний прогон с подставными ответами не проверяет корректность реальных credentials.

## Постеры

MoviePosterViewModel загружает изображение с https://image.tmdb.org/t/p/: w185 для pixelSize <= 270, иначе w500. При ошибке используется локальный asset, если он задан, или заглушка. UIKit асинхронно подготавливает уменьшенное изображение. Постоянное офлайн-хранилище постеров не реализовано.

## Личные данные

Оценка и комментарий сначала сохраняются в SwiftData. Отдельная кнопка отправляет только число в TMDB. Гостевая сессия с датой истечения хранится в памяти клиента; после перезапуска создаётся новая. При обнаружении истёкшей сессии клиент сбрасывает её и предлагает повтор. Успешно отправленное число отмечается в текущей ViewModel, а не в постоянном хранилище.

Удаление локальной оценки не удаляет удалённую. Комментарии и желаемое остаются на устройстве. Это отдельная отправка оценки, а не полноценная синхронизация аккаунта.

## Проверки

Три TMDBClientTests прошли 22 октября: поиск, отправка оценки с повторным использованием сессии, отказ доступа. Они используют подставные ответы. Проверка реального сервиса остаётся отдельным шагом по прямому указанию пользователя.
